🧮 Calculadora Web

Uma calculadora simples e funcional desenvolvida com HTML, CSS e JavaScript, apresentando uma interface moderna com tema espacial.

🚀 Tecnologias Utilizadas

HTML5: Estruturação dos elementos da calculadora.

CSS3: Estilização, layout flexível (Flexbox) e fundo estilizado.

JavaScript: Lógica de cálculo e manipulação dos valores.

✨ Funcionalidades

Realização das quatro operações matemáticas básicas: soma (+), subtração (-), multiplicação (*) e divisão (/).

Botão AC (All Clear) para limpar toda a tela.

Botão DE (Delete) para apagar o último caractere digitado.

Design responsivo e centralizado na tela.
